# 玉語軒 · JADE & SILENCE

香港私人玉器收藏網站 — 15 件藏品，中英雙語，附完整鑑定檔案。

A static, bilingual (Traditional Chinese / English) catalogue site for a private
Hong Kong jade collection. No build step, no dependencies, no framework.

---

## 一、如何開啟

最簡單的方式，在專案資料夾執行：

```bash
cd /Users/majunyao/Documents/jade
python3 -m http.server 8099
```

然後開啟 <http://127.0.0.1:8099>。

> 直接雙擊 `index.html` 也可以瀏覽，但 `python3 -m http.server` 較接近真實網站環境。

## 二、網站結構

| 檔案 | 內容 |
|---|---|
| `index.html` | 首頁：主視覺（馬上封侯）、藏品精選、關於本軒、為何選擇本軒、鑑賞流程 |
| `collection.html` | 藏品目錄：15 件，材質篩選 + 排序（篩選可用網址分享，如 `?group=white`） |
| `contact.html` | 預約私人鑑賞、洽詢表格（直接開 WhatsApp）、常見問題 |
| `pieces/*.html` | 15 個藏品頁 |
| `assets/css/main.css` | 設計系統（色彩、字體、元件、響應式） |
| `assets/js/main.js` | 語言切換、篩選排序、圖片放大、燈箱、WhatsApp 洽詢 |
| `assets/images/` | 108 個最佳化圖片（每張 3 種尺寸，響應式） |
| `assets/data/pieces.json` | 15 件藏品的結構化資料（供日後接駁 CMS 或 App） |

## 三、藏品頁面包含甚麼

每個藏品頁（`pieces/`）依拍賣行規格排列：

1. 藏品編號、名稱、英文名
2. 材質／玉種／器型標籤 + **風格參照**（非科學斷代）標記
3. 建議鑑賞價：**面議**
4. 三層行動呼籲：**預約鑑賞** → 洽詢此藏品 → 提出您的價格
5. 圖片庫（點擊放大、燈箱、縮圖切換、滑鼠放大）
6. 「想看得更仔細？」— 索取更多照片／影片
7. 藏品上下件導覽（`07 / 15` + 可直接跳號）
8. 完整規格表（含**調水處理**與**處理狀態**披露）
9. 影像詮釋（每個角度的說明）
10. 專業鑑賞筆記
11. 文化寓意與用途
12. 品相說明 & 賣家承諾
13. 聯絡洽詢（WhatsApp／WeChat）
14. 同類珍藏

## 四、修改內容

內容由 `assets/data/pieces.json` 與各 HTML 直接控制，可直接用文字編輯器修改。

**改電話／微信**：搜尋 `63405393` 與 `Roychan-Aurora`，會出現於頁尾、
每個藏品頁的聯絡區、以及浮動 WhatsApp 按鈕。共 3 處樣式，
但分佈在多個檔案 —— 最穩妥是用編輯器的「全資料夾取代」。

**改品牌名**：搜尋 `玉語軒` 與 `Jade &amp; Silence`。

**改價錢**：目前全部藏品皆為「面議」。如要為個別藏品標價，
在該 `pieces/*.html` 中把 `<span class="price__val">面議</span>`
改為實際價錢，並移除同段落的面議說明。

**新增藏品**：
1. 把照片放入 `assets/images/`，命名 `新代號-01.jpg`、`-02.jpg`……
2. 複製任何一個 `pieces/*.html` 作為範本，替換文字與圖片路徑
3. 在 `collection.html`、`index.html` 加入卡片連結

## 六、設計說明（採用之高端慣例）

研究報告見 `premium-jade-ux-research.md`（1,900+ 行，89 個來源），
以下為已落實的主要慣例：

- **色彩**：暖墨 `#14110F`、宣紙 `#F7F4EE`、啞金 `#B08D57`、硃砂印 `#A3372A`
- **字體**：Noto Serif TC（中文宋體）配 Cormorant Garamond（西文襯線）——正確的
  宋體↔襯線 / 黑體↔無襯線配對邏輯；中文正文字距為 `0`（中文不應加字距）
- **物件攝影用 `object-fit: contain`**，不裁切——手把件的輪廓與平安扣的圓度就是產品本身
- **誠實的斷代**：每件藏品頁標示「風格參照 · 非科學斷代」，頁尾亦註明「年代參考僅為
  風格判斷，非科學斷代」
- **面議的處理**：三層 CTA、五條疑問解答、四小時回覆承諾
- **無障礙與效能**：`prefers-reduced-motion` 支援、響應式圖片（`srcset`）、
  延遲載入、語意標籤

## 七、上線前建議（來自研究報告）

以下為報告中標示為高影響力、但需要您提供資料才能完成的項目：

1. **沁色專項說明** —— 005／006／007／011／017（帶皮籽料）與 008（水銀滲沁）
   可各加一段學術性沁色說明。這是同業無人做到的差異化內容。
2. **第三方檢測證書** —— 翡翠處理狀態（A／B／C 貨）目前未作結論，
   如取得 NGTC 或 HKJSL 報告，可加入證書專頁。
3. **自然日光照片** —— 每件補一張日光下的照片，是成本最低、效果最強的抗疑慮資產。
4. **透光照與手持比例照** —— 手把件尤其需要。
5. **交付與法律條款** —— 出口／入口合規與退換條款，建議由熟悉文物出入口的律師審閱。
6. **簡體中文** —— 如要觸及內地買家。
